# 🧪 گرانول‌لب — سامانهٔ وب و پنل مدیریت آزمایشگاه گرانول

سامانهٔ جامع برای آزمایشگاه گرانول، شامل **وب‌سایت عمومی** (معرفی آزمایشگاه و خدمات) و **پنل مدیریت جامع** (مدیریت آزمایش‌ها، ثبت گزارش، پاسخ آنلاین، پرداخت آنلاین) به‌طوری‌که مشتری بتواند نتیجهٔ آزمایش خود را در پنل شخصی ببیند.

## پشتهٔ فناوری

| لایه | انتخاب |
|---|---|
| بک‌اند | Laravel (PHP 8.x) |
| فرانت | Blade + کتابخانهٔ CSS فارسی/RTL (فونت Vazirmatn) |
| پایگاه‌داده | MySQL (تولیدی) / SQLite (توسعه) |
| پرداخت | درگاه آنلاین — نهایی‌سازی پس از پرسشنامهٔ مشتری |
