# تعریف «انجام‌شده» (Definition of Done)

یک آیتم بک‌لاگ (Issue) فقط وقتی «انجام‌شده» است که:

- [ ] همهٔ معیارهای پذیرش داستان برآورده شده باشد.
- [ ] کد در شاخهٔ feature ساخته و با PR به `main` merge شده باشد (بدون push مستقیم).
- [ ] حداقل یک بررسی کد (review) روی PR انجام شده باشد.
- [ ] تست‌های مربوط نوشته و پاس شده باشند (Feature test لاراول برای بک‌اند؛ تست مرور دستی برای UI مستندشده در PR).
- [ ] رابط کاربری فارسی و RTL با فونت استاندارد پروژه باشد؛ بدون متن جاماندهٔ انگلیسی در UI فارسی.
- [ ] برچسب‌ها و Milestone آیتم به‌روز شده و Issue با ذکر کامیت بسته شده باشد.
- [ ] تغییرات دیتابیس با Migration ثبت شده باشد (بدون دست‌کاری دستی).
- [ ] روی استیجینگ دیپلوی و دیده شده باشد (برای آیتم‌های نمایش‌پذیر).

## تکمیلی برای اپیک‌های حساس

- GR-402 (نتایج): کنترل دسترسی تست شده — کاربر به نتیجهٔ دیگران دسترسی ندارد.
- GR-501 (پرداخت): تراکنش‌ها idempotent، لاگ کامل، عدم نگهداری دادهٔ کارت.
