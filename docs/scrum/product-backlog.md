# بک‌لاگ محصول — گرانول‌لب

> منبع حقیقت کارهای محصول. هر داستان شناسهٔ `GR-xxx`، اولویت MoSCoW و معیار پذیرش دارد.
> اولویت‌ها بر اساس اعلام اولیهٔ مشتری‌اند و پس از پرسشنامهٔ Sprint 0 تثبیت می‌شوند.

## اپیک‌ها

| اپیک | شرح | اولویت |
|---|---|---|
| E1 — وب‌سایت عمومی | معرفی آزمایشگاه، خدمات، تماس | Must |
| E2 — حساب‌ها و نقش‌ها | ثبت‌نام/ورود؛ نقش‌های مدیر، کارمند، مشتری | Must |
| E3 — پنل مدیریت | مدیریت آزمایش‌ها، پذیرش نمونه، وضعیت، کارکنان | Must |
| E4 — گزارش نتیجه | ثبت نتیجه توسط کارمند؛ مشاهده در پنل مشتری | Must |
| E5 — پرداخت آنلاین | صدور صورتحساب و پرداخت درگاهی | Must (وابسته به انتخاب درگاه) |
| E6 — اعلان‌ها | اطلاع آمادگی نتیجه/پرداخت (پیامک یا داخل برنامه) | Should |
| E7 — محتوای آموزشی | راهنمای آزمایش‌ها، آماده‌سازی قبل از آزمایش | Could |

## موارد باز برای مشتری (برچسب question)

- انتخاب درگاه پرداخت و پیکربندی آن (GR-501)
- نیاز به پیامک یا اعلان داخل برنامه (GR-601)
- آیا اتصال به دستگاه‌های آزمایشگاهی (LIS) لازم است؟
- نام/برند و لوگوی رسمی برای وب‌سایت عمومی
- قالب نمونهٔ گزارش نتیجهٔ فعلی آزمایشگاه (برای طراحی فرم)
