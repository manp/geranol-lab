# پرسشنامهٔ کشف نیازمندی — گرانول‌لب

> **نسخهٔ پاسخ‌پذیر آنلاین:** https://pages.nsar.ir/p/DfmJMJUd0PmvWOu1cebddiaE/ (فرم در حال بازسازی مطابق این نسخه است؛ در صورت تغییر لینک، همین سطر به‌روز می‌شود)
> **تکمیل چندنوبتی:** مشتری می‌تواند فرم را در فرصت‌های مختلف پر کند؛ پیش‌نویس ذخیره می‌شود و پس از ثبت، با کد/لینک ویرایش قابل تغییر است.
> فقط سؤال ۱ الزامی است. **برند و لوگو را کارفرمای پروژه طراحی می‌کند** و دربارهٔ آن از مشتری سؤال نمی‌شود؛ میزبانی، دامنه و محتوای تصویری/ویدیویی هم بر عهدهٔ کارفرماست.

زمینه: آزمایشگاه گرانول، آزمایشگاه **گیاه‌پزشکی** است و آزمایش‌های **آب، خاک و کود** نیز انجام می‌دهد (آزمایشگاه انسانی/پزشکی نیست — واژگان گزارش و نمونه‌ها بر همین اساس است).

## بخش ۱ — شناخت آزمایشگاه
1. نام رسمی آزمایشگاه و شهر/منطقهٔ فعالیت؟ *(الزامی)*
2. چرخهٔ کار امروز از پذیرش نمونه تا تحویل جواب چگونه انجام می‌شود؟
3. روزانه به‌طور میانگین چند نمونه می‌گیرید؟ فصل‌های پرکار کدام‌اند؟
4. چند نفر پرسنل دارید و نقش هر کدام چیست؟ (پذیرش، کارشناس آزمایش، کارشناس توصیهٔ کودی، مدیر، حسابداری)

## بخش ۲ — خدمات و آزمایش‌ها
5. کدام گروه‌های آزمایش را انجام می‌دهید؟ (تشخیص آفات و بیماری‌های گیاهی / آنالیز خاک / آنالیز آب آبیاری / آنالیز کود / باقیماندهٔ سموم و آفت‌کش‌ها / آزمون بذر / سایر)
6. آزمایش‌های پرتقاضا و قیمت هر گروه را کوتاه بنویسید.
7. در گزارش آنالیز خاک، توصیهٔ کودی هم ارائه می‌دهید؟ (بله/خیر)
8. برگهٔ گزارش فعلی چه ستون‌ها و بخش‌هایی دارد؟

## بخش ۳ — نمونه و مراجعان
9. نمونه‌ها را مراجع می‌آورند یا نمونه‌برداری در مزرعه هم انجام می‌دهید؟ آیا درخواست آنلاین نمونه‌برداری لازم است؟ (مراجع خودشان می‌آورند / نمونه‌برداری مزرعه‌ای داریم / هر دو — درخواست آنلاین لازم است / هر دو — درخواست آنلاین لازم نیست / سایر)
10. مراجعان اصلی چه کسانی‌اند؟ (کشاورز / گلخانه‌دار و باغدار / شرکت تولید سم و کود / جهاد کشاورزی و مراکز خدمات کشاورزی / پژوهشگر و دانشجو / سایر)
11. گزارش‌ها به نهاد رسمی خاصی ارجاع می‌شود؟ (مثلاً جهاد کشاورزی، سازمان محیط زیست، مؤسسهٔ خاک و آب)

## بخش ۴ — پنل مدیریت و گردش کار
12. در پنل مدیریت چه چیزهایی مدیریت شود؟ (نمونه‌ها و آزمایش‌ها / قیمت‌ها / پرسنل و دسترسی‌ها / گزارش‌ها و آرشیو / امور مالی / چاپ گزارش با سربرگ رسمی / صورتحساب رسمی)
13. گردش وضعیت نمونهٔ پیشنهادی — ثبت‌شده ← در حال آزمایش ← آماده ← تحویل‌شده — مناسب است؟ (بله/خیر)
14. مشتری چگونه وارد پنل خود شود؟ (شمارهٔ موبایل + کد پیگیری / کد ملی / کد رهگیری روی برگهٔ گزارش / سایر)

## بخش ۵ — پنل مشتری، پرداخت و اعلان
15. مشاهدهٔ نتیجه فقط پس از پرداخت آزاد شود؟ (بله/خیر)
16. درگاه پرداخت موردنظر؟ (زرین‌پال / آیدی‌پی / به‌پرداخت / فرقی ندارد / سایر)
17. اطلاع «نتیجهٔ آماده است» چگونه برسد؟ (پیامک — سرویس داریم / پیامک — باید تهیه شود / اعلان داخل پنل / هر دو)

## بخش ۶ — وب‌سایت و راه‌اندازی
18. چه صفحات و امکاناتی در وب‌سایت عمومی می‌خواهید؟ (خانه / خدمات و قیمت‌ها / راهنمای آماده‌سازی و نمونه‌برداری / سؤالات متداول / فرم تماس / دربارهٔ آزمایشگاه)
19. مهلت راه‌اندازی خاصی دارید؟ آموزش پرسنل حضوری باشد یا راهنمای متنی/ویدیویی؟
